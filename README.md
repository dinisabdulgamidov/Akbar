# АКБАР МАРКЕТ

Первая версия адаптивной витрины онлайн-магазина в Нурадилово, Республика Дагестан.

## Доставка
- Нурадилово — бесплатно при любой сумме.
- Солнечное, Хамавюрт, Борагангечу — 150 ₽ при сумме менее 1 000 ₽.
- От 1 000 ₽ — бесплатно во все четыре села.

## Статус
Каталог, поиск, корзина и расчёт доставки — демонстрационные. Реальные заказы, оплата и серверная часть пока не подключены.
